# Blinkit Sales Analytics Report (DA)

## Project Overview

This project focuses on analyzing Blinkit sales data using Power BI to understand business performance, customer behavior, product demand, and sales trends. The dashboard converts raw sales data into meaningful insights to support better business decisions.

## Problem Statement

Blinkit handles thousands of grocery orders across different cities, products, and payment methods. Analyzing sales performance, customer preferences, delivery efficiency, and profitability from raw data can be challenging. This project aims to simplify business analysis through interactive dashboards and visual insights.

## Dataset Information

The dataset contains information related to:

* Order Details (Order ID, Order Date, Delivery Date, Delivery Mode)
* Customer Details (Customer ID, Gender, Age Group, Membership Type)
* Location Details (State, City, Region, Store Location)
* Product Details (Product Name, Category, Brand, Sub-Category)
* Sales Metrics (Unit Price, Quantity, Discount, Total Sales, Profit)
* Transaction Details (Payment Method, Customer Rating, Return Status)

## Data Preprocessing

* Removed duplicate records
* Handled null/blank values
* Converted date columns into proper format
* Verified numerical data types
* Standardized column names
* Checked inconsistent category and city names
* Created KPIs like Profit Margin and Average Order Value

## Tools & Technologies Used

* Power BI
* Excel / CSV Dataset
* Data Cleaning
* Data Visualization
* DAX Functions

## Dashboard Features

* Sales Performance Analysis
* Product Category Analysis
* Customer Behavior Insights
* Payment Method Analysis
* Regional Sales Analysis
* Profit & Discount Tracking

## Key Insights

* Identified top-selling products and categories
* Analyzed customer purchasing behavior
* Tracked sales and profit trends
* Compared performance across regions and cities
* Evaluated payment preferences and return status

## Conclusion

This project helps understand Blinkit's sales performance and customer behavior using data visualization. The dashboard provides useful insights for improving sales, customer satisfaction, and business decisions.
